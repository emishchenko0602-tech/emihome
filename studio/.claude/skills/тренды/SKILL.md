# Поиск темы

Первый шаг конвейера. На выходе — **одна тема с кодовым словом**, дальше по ней
работают `/реф`, `/карусель`, `/гайд`, `/воронка`, `/рилс`.

## 1. Проверь настройки ниши

Ниша задана в `scripts/.niche.json` (создаёт мастер установки):

```json
{ "hashtags": ["нейросети", "aiагент"], "donors": ["акк1", "акк2"], "language": "ru" }
```

Если файла нет или доноров меньше пяти — спроси клиента, за какими аккаунтами
и хэштегами следить, и допиши. Без доноров поиск даёт случайный мусор.

## 2. Запусти парсинг

```bash
node scripts/search-instagram.mjs --days 30 --top 25 --min-comments 300 > workspace/trends/last.md
```

Пиши вывод **в файл через `>`**, не через пайп: при запуске в фоне вывод
буферизуется и лог остаётся пустым до самого конца.

Порог `--min-comments` подбирается под размер ниши: в маленькой нише 300 отсечёт всё,
начни со 100 и подними, если кандидатов слишком много.

## 3. Отбери кандидатов по трём фильтрам

1. **Свежесть** — пост младше недели. Старше двух недель не берём: тема уже разошлась.
2. **Попадание в нишу** — тема должна вести к тому, что клиент продаёт или чем занимается.
3. **Кодовое слово свободно** — сверь с `workspace/registry.json`.

Про третий фильтр отдельно: воронка в ChatPlace ловит слово по вхождению (`contains`).
Если новое слово содержит старое или содержится в нём (СКРИПТ ↔ СКРИПТЫ, КОД ↔ КОДЕР),
сработают **две воронки сразу** и человек получит два ответа в директ. Слово с коллизией
не берём, даже если тема отличная — берём синоним.

## 4. Покажи клиенту 3–4 темы

Таблицей: тема · метрики · возраст · ссылка · предлагаемое кодовое слово · чем зацепит.
**Выбор темы — решение человека**, сам не выбирай. Это одна из четырёх точек, где
клиент вмешивается в конвейер.

## 5. Заведи запись в реестре

После выбора добавь в `workspace/registry.json`:

```json
{ "slug": "...", "keyword": "СЛОВО", "source": "<ссылка на реф>", "date": "YYYY-MM-DD",
  "formats": {}, "status": {} }
```

Дальше передавай управление скиллу `/реф`.

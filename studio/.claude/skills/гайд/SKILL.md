# Гайд на сайт

Гайд — то, что человек получает в директ за кодовое слово. Без живой страницы
воронку включать нельзя: кнопка поведёт в никуда.

## Четыре столпа канона

1. **Реальные источники.** Каждая команда взята из документации или репозитория, не
   по памяти. Блок «Источники» внизу обязателен и не бывает пустым.
2. **Связная проза.** Абзацы, которые читаются подряд. Не список из семи пунктов
   вместо текста.
3. **Тёплый editorial-дизайн.** Он уже в каркасе — компоненты из `site/components/Guide.tsx`,
   стили из `.prose-editorial`. Свою вёрстку не изобретаем.
4. **Две инфографики.** Не украшение: первая — общая схема, вторая — порядок действий
   или сравнение.

## Гайд обязан добавлять к рефу

Референс — это 40–60 секунд перечисления. Гайд, который просто пересказывает его
словами, не нужен никому. Добавляй то, чего в рефе нет: в каком порядке ставить и
почему, где инструменты конфликтуют друг с другом, чего они НЕ умеют, честная оговорка
про ограничения. Это и есть разница между «перевёл виралку» и «сделал полезное».

## 1. Страница

Скопируй `site/app/guides/primer-gayda/page.tsx` в `site/app/guides/<slug>/page.tsx`
и наполни. Кирпичи — `GuideHero`, `Figure`, `Callout`, `Sources`, `KeywordCTA`.

Добавь запись в `site/lib/guides.ts` — одна запись = карточка на витрине и в списке.

## 2. Инфографики

Спек `workspace/guides/<slug>/infographics.json`:

```json
{
  "slug": "<slug>",
  "outDir": "site/public/guides/<slug>",
  "items": [
    { "file": "infographic-01.png", "title": "…", "subtitle": "…", "intro": "…",
      "cards": ["1 ЗАГОЛОВОК — пояснение | example chip: «…»"], "takeaway": "…" }
  ]
}
```

```bash
node scripts/guide-infographics.mjs workspace/guides/<slug>/infographics.json
```

Нужен поднятый Chrome с портом 9222 (как для карусели).

## 3. Деплой — ВСЕГДА две команды

```bash
node scripts/site-deploy.mjs
```

Скрипт делает сборку и **переводит домен на неё** — на Vercel это `alias set`,
на Layero флаг `--promote`. Без второго шага домен остаётся на предыдущей сборке:
страница отдаёт 200, но старую — и это выглядит как «деплой не сработал».

Скрипт сам проверяет ответ и ругается, если пришло не 200. Проверка повторяется
с паузой: на Layero контейнер поднимается по запросу, и первые полминуты после
деплоя домен может отдавать 404 при исправной сборке.

## 4. Проверь перед тем, как звать воронку

- страница гайда отдаёт 200;
- обе инфографики открываются по прямым ссылкам;
- список гайдов показывает новую карточку.

Только после этого — `/воронка`.

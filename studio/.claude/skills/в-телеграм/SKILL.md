# Телеграм: приёмник и витрина

Бот клиента — единственная точка обмена файлами. Туда он кидает своё видео,
оттуда забирает готовые посты и ролики.

## Забрать исходник от клиента

```bash
node scripts/reel-inbox.mjs
```

Слушает бота и складывает присланные видео в `workspace/reels/_inbox/`.
Держи запущенным, пока ждёшь запись. Telegram сжимает видео до 720p — для монтажа
это не критично.

## Отправить готовое

```bash
node scripts/send-to-telegram.mjs [id ...] [--dry]
```

Данные берёт из `workspace/registry.json`, после отправки сам проставляет статус.

Произвольные файлы (один ролик, один PNG) отправляются напрямую — не заводи ради
этого запись в реестре.

## Правила отправки на приёмку

- **Подпись идёт отдельным сообщением текстом**, а не подписью к альбому: из подписи
  под фото её неудобно копировать в Instagram.
- Карусель отправляй **альбомом целиком**, а не по одному слайду.
- Вместе с контентом коротко напиши, что это и что с этим делать: какое кодовое слово,
  куда ведёт ссылка, что ещё не готово.
- Ничего не отправляй, пока не проверил: у ролика — звук, у гайда — 200, у воронки —
  живой путь.

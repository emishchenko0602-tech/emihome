# Рилс: автомонтаж говорящего видео

Один конвейер на два исходника. Монтаж рисует Omni во Flow по нашим сторибордам —
своей вёрстки поверх видео здесь нет.

```
исходник → нарезка по фразам → сториборд на каждую часть → Omni монтирует
        → сборка → сверка звука → приёмка
```

## 1. Исходник

**Вариант А — живая запись клиента.** Забери из бота (`node scripts/reel-inbox.mjs`).
Сначала напиши клиенту сценарий-суфлёр на 20–40 секунд: личный отказ или конфликт в
первой фразе, одна цифра, кодовое слово в финале.

**Вариант Б — аватар HeyGen.** Аватар читает текст **своим голосом HeyGen**
(`create_video_from_avatar` с текстом сценария). Клонирование голоса в этой сборке
не используется.

Два правила текста, оба обязательны:
- **ни одного тире** — синтез читает его как паузу или мусор;
- **иностранные названия транслитом** («Омни Роут», «Антропик»): латиницу русский
  синтез читает по буквам. На экране во врезках названия остаются английскими.

## 2. Нарезка — по границам фраз

```bash
python scripts/transcribe.py <исходник>.mp4 --words
```

Из пословных таймингов возьми паузы между словами и режь по ближайшей к 10/20/30 секундам.
Части по 8–10 секунд: Omni режет вход примерно на десятой секунде, длинную часть
он обрежет молча.

Не режь по кратным десяти вслепую — слово разорвётся пополам и склейка будет слышна.

## 3. Сториборды

Спек `workspace/reels/<slug>/sb-spec.json`: стиль задаётся **один раз**, по частям
описываются только панели.

```json
{ "styleName": "кинетик",
  "style": "pure jet black background, bold orange accents, bold condensed sans, kinetic typography with overshoot punches, no gradients, no glass, no texture",
  "outDir": "workspace/reels/<slug>/storyboard",
  "srcDir": "workspace/reels/<slug>/parts",
  "parts": [ { "n": 1, "panels": [
     { "at": 2.4, "shot": "FULLSCREEN SPEAKER", "timing": "the first moment of this part",
       "desc": "что появляется в кадре" } ] } ] }
```

Стиль в этой сборке один — «кинетик», он описан в `styles/kinetik.md`: что подставлять
в промпты, какие две обязательные строки-запрета ставить и на чём он ломается.
Прочитай файл перед первым роликом. Набор из восемнадцати стилей — отдельное
дополнение, не в этой сборке.

```bash
node scripts/storyboard-batch.mjs workspace/reels/<slug>/sb-spec.json
node scripts/omni-prompt.mjs workspace/reels/<slug>/sb-spec.json
```

Почему `at` и `timing` — разные поля: `at` идёт только в нарезку кадра, а в текст
промпта тайминг попадает **словами**. Числовые таймкоды Omni рисует прямо в кадр.

По той же причине в промпте не бывает hex-цветов и имён файлов — цвет описывается
словом («ярко-оранжевый»).

**Что НЕ кладут в панель сториборда:** скриншоты и мелкий текст. Omni перерисовывает
их в кашу. Такие врезки ставятся отдельным слоем поверх готового видео.

**Без шапки.** Никаких «PART 1 of 6» и заголовков на самом борде — модель утащит их в кадр.

**Две строки-запрета в каждый промпт монтажа** (иначе стиль ломается — подробности
в `styles/kinetik.md`):

```
Output ONE full-screen composition always: never show storyboard panels, numbers, grids or labels.
Only ONE headline on screen at a time: it fully disappears before the next appears, never overlapping.
```

## 4. Заливка во Flow

```bash
node scripts/flow-prep-uploads.mjs workspace/reels/<slug>/parts <префикс>
node scripts/flow-upload-video.mjs <файл>
node scripts/flow-assets-check.mjs <префикс>1-board <префикс>1-snd
node scripts/flow-omni-queue.mjs <префикс> workspace/reels/<slug>/storyboard 1 6
```

**Части заливаются только со звуком.** Немых заливок нет: на немом входе Omni
сочиняет озвучку сам — чужим голосом, наполовину по-английски и не по сценарию.
Подготовка падает, если у части нет дорожки, — это защита, а не придирка.

Если часть валится по правилам площадки из-за речи — **переписывай реплику**, а не глуши звук.

Порядок вложений: сториборд первым, видео вторым.

## 5. Четыре отказа, которые выглядят как успех

1. **Режим сбросился на «Frames»** — Omni отчитывается успехом и возвращает копию
   исходника без единого элемента монтажа. Самый опасный случай: внешне похоже на
   результат. Проверяй глазами, а не по статусу.
2. **Квота кончилась молча** — ни ошибки, ни сообщения: просто исчезает кнопка
   генерации. Признак — чипы есть, промпт есть, кнопки нет.
3. **Длинный промпт роняет джобу** — рабочий потолок около 1400 символов.
4. **Первый файл на новом аккаунте уезжает в никуда** — его съедает диалог согласия.
   Поэтому после заливки всегда `flow-assets-check`, а не доверие логу.

Результаты в гриде лежат вперемешку с загруженными исходниками, и у аплоадов статус
тоже «успешно». Опознавай по картинке: скачай кандидатов, сними по кадру, посмотри —
у смонтированного есть графика, у аплоада её нет.

## 6. Сборка

```bash
node scripts/omni-assemble.mjs workspace/reels/<slug>/omni \
     workspace/reels/<slug>/parts <префикс> workspace/reels/<slug>/final.mp4
```

Звук в финале — **от Omni**. Подменять дорожку на оригинал (`--src-audio`) можно
только по прямой просьбе клиента на конкретном ролике: молчаливая подмена выглядит
как «всё в порядке», хотя на деле ролик другой.

## 7. Сверка звука — обязательный шаг

```bash
python scripts/transcribe.py workspace/reels/<slug>/final.mp4 --txt
```

Сверь с текстом сценария: все реплики на месте, нет задвоений и выпадений, границы
частей совпадают. Не сошлось — ролик не идёт на приёмку.

## 8. Приёмка

Один ролик за раз. Отправь в бота (`/в-телеграм`) и дождись решения клиента, прежде
чем собирать следующий. Партия из четырёх роликов, собранная без промежуточной приёмки,
однажды была забракована целиком.

# Карусель и пост-инфографика

Слайды **генерирует нейросеть** (GPT Image в ChatGPT через браузер), а не верстает HTML.
Движок один — `scripts/f2-from-ref.mjs`, он читает спек. Код править не нужно.

## 1. Подними Chrome с отладочным портом

Запускай сам, не проси клиента:

```powershell
Start-Process "C:\Program Files\Google\Chrome\Application\chrome.exe" -ArgumentList "--remote-debugging-port=9222","--user-data-dir=<КОРЕНЬ>\auth\chrome-auto-profile","--no-first-run","--no-default-browser-check","https://chatgpt.com/"
```

Логин в профиле уже сохранён после установки.

## 2. Напиши спек

`workspace/carousel/<slug>/f2-spec.json`:

```json
{
  "slug": "<slug>",
  "outDir": "workspace/carousel/<slug>/format2",
  "refDir": "workspace/refs/<slug>/<папка кадров>",
  "facePhoto": "workspace/assets/photos/author/author.jpg",
  "designNote": "дизайн-код словами из /реф",
  "slides": [
    { "name": "cover", "face": true, "prompt": "что на слайде" },
    { "name": "01", "ref": "frame-012.jpg", "prompt": "…" }
  ]
}
```

`ref` — необязательное поле. Без него слайд рисуется в вашем стиле без референса.

## 3. Канон карусели — соблюдать всегда

- **Обложка кликбейтная**, а не описательная. Не «5 плагинов Claude Code», а обещание
  выгоды или конфликт: «Платишь за Claude? Эти 5 плагинов раздают то же даром».
- **Пилюля «листай →»** на обложке.
- **Один слайд — одна мысль**, слово-удар крупно.
- **Два финальных слайда:** мокап директа с кодовым словом и финал с призывом.
- Всё, что должно читаться, **задаётся текстом в промпте** — включая мелкие подписи
  в подвале. Что не задано словами, модель допишет от себя и с ошибкой.

## 4. Стоп-показ до рендера — правило

Перед генерацией собери HTML-макет всех слайдов (текст + план композиции) в
`workspace/carousel/<slug>/preview/index.html`, подними `python -m http.server`
и **покажи клиенту**. Дальше не идёшь, пока он не принял.

Это не формальность: на реальном прогоне такой показ поймал отсутствие кликбейта на
обложке и нехватку CTA-слайдов. Одна проверка сэкономила восемь перегенераций.

## 5. Генерь

```bash
node scripts/f2-from-ref.mjs workspace/carousel/<slug>/f2-spec.json
node scripts/f2-from-ref.mjs <spec> --only 1,3      # выборочно
node scripts/f2-from-ref.mjs <spec> --redo 4        # перегенерить слайд
```

## 6. Грабли, которые стоили перегенераций

- **Чужое лицо.** Если реф-кадр содержит крупный портрет другого человека, модель
  копирует ЕГО и игнорирует фото автора, даже при явном запрете. На слайдах, где может
  появиться человек — даже мелко, даже в аватарке чата — **реф-кадр не давать вообще**.
- **Слайд без вложений падает** с «composer not found»: у слайдов с картинками загрузка
  файла давала фору на догрузку страницы. Движок это уже ждёт явно, но если увидишь
  такую ошибку — просто перезапусти этот слайд через `--redo`.
- **Плотный текст на рескине уезжает в английский.** Текстонасыщенные слайды делай
  без `ref`, описанием дизайна словами.

## 7. Пост-инфографика

Тот же движок, другой спек: один лист 1080×1350, свой стиль (например рукописный
разворот блокнота). Материал — из того же `/реф`. Это второй формат для другого охвата,
а не копия карусели.

## 8. Подпись

Подпись к посту: до 1000 символов, кликбейтный хук первой строкой, личный опыт от
первого лица, кодовое слово в призыве. **Прогони через антиклише** (скилл `humaniser`),
затем положи в `workspace/carousel/<slug>/caption.txt`.

Проверь машинно и добейся нуля стопов:

```bash
python .claude/skills/humaniser/scripts/lint.py workspace/carousel/<slug>/caption.txt
```

Длинные тире и точки в конце абзацев — стоп, с ними подпись не публикуется.

Обнови `workspace/registry.json` и передай в `/в-телеграм`.

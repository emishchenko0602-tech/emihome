# Автоворонка на кодовое слово

Человек пишет слово в комментарии или в директ — получает гайд, а через сутки
предложение. Всё это делает ChatPlace, у клиента свой аккаунт и свой ключ.

## Порядок обязателен

**Воронка создаётся ПОСЛЕ того, как страница гайда отдаёт 200.** Наоборот — кнопка
ведёт на 404, и первые же люди уходят.

## 1. Проверь коллизию слова

ChatPlace ловит слово по вхождению (`contains`). Слово, которое содержит уже занятое
или содержится в нём, включит **две воронки сразу**, и человек получит два ответа
в директ. Сверь со всеми словами в `workspace/registry.json`. Есть пересечение — бери
синоним, а не «почти такое же».

## 2. Создай одним вызовом

Инструмент — `automations_quick_setup`, шаблон `base`. Ручную сборку блоками не
используем: на ней ошибки с осиротевшими блоками и перевёрнутыми условиями.

Схема, которая работает:

```
триггер: commentContains + messageContains
слова:   СЛОВО · Слово · слово · слова · латиницей · с типичной опечаткой
M1 приветствие + кнопка «Да, скидывай»
  → M2 карточка + URL-кнопка «Открыть разбор» → ссылка на гайд
    → ACT add_tag click-link → ACT make_conversion
      → DELAY 18ч → M4 предложение
ветка напоминания: DELAY 10м → условие has_tags click-link
  → кликнул: тупик · не кликнул: M3 напоминание
+ autoAnswers: 2–3 ответа в комментариях под постом
```

## 3. Проверь два места после создания

1. **Куда прицеплен дожим.** Сообщение с кнопкой дальше по `nextStepId` НЕ продолжается —
   поток идёт только по клику. Поэтому предложение вешается на **хвост клик-пути через
   экшены** (`make_conversion`), а не на сообщение с кнопкой. Иначе блоки повисают
   и не срабатывают никогда.
2. **Текст сообщений.** Быстрое создание умеет прислать текст со ссылкой, обёрнутый
   в моноширинный блок — в директе это выглядит как кусок кода. Прочитай, что реально
   записалось, и поправь через обновление сообщения.

## 4. Проверь живьём

Напиши слово боту сам и пройди путь до конца: приветствие → кнопка → ссылка открывается →
тег проставился. Только после этого говори клиенту, что воронка готова.

Занеси слово и id автоматизации в `workspace/registry.json`.

# humaniser — антиклише-фильтр

Навык MassMedia Studio. Последний проход перед публикацией: снимает с готового
текста машинный почерк и возвращает живую речь, ничего не досочиняя.

## Состав

| Файл | Что внутри |
|---|---|
| `SKILL.md` | вход: когда включается, как гонять, где границы |
| `prompt.md` | рабочий свод правил, его читают скиллы-писатели напрямую |
| `references/patterns.md` | каталог паттернов с примерами до и после |
| `scripts/lint.py` | детерминированная проверка чистовика |

## Проверка текста

```bash
python scripts/lint.py caption.txt
python scripts/lint.py guide.md --allow-dots   # лонгрид: концевые точки разрешены
python scripts/lint.py --self-test
```

СТОП — жёсткие запреты и следы копипаста из чат-бота, с ними не публикуем.
ЗАМЕТКА — мягкие маркеры, считаются кластерами.

## Два режима

**Руками.** «Прогони через humaniser», «убери AI-клише», «сделай текст человечнее».

**Внутри писателя.** Скиллы, которые пишут подписи, карусели, гайды, сценарии
роликов и сообщения бота, читают `prompt.md` на финальной фазе и применяют его
как модуль.

## Голос автора

Берём из прошлых текстов автора в `workspace/`: длина фраз, лексика, табу,
типичные обороты. Текстов ещё нет — фильтр работает по общим правилам и говорит
об этом в конце выдачи.

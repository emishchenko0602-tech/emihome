# Сайт-витрина студии

Минимальный сайт на Next.js: главная, список гайдов и страницы гайдов по канону.
Агент дописывает сюда гайды сам — руками этот код править не нужно.

## Что где лежит

| Путь | Что это |
|---|---|
| `site.config.json` | бренд, хэндл, ссылки — правится один раз при установке |
| `lib/guides.ts` | реестр гайдов: одна запись = одна карточка на сайте |
| `app/guides/<slug>/page.tsx` | сам гайд |
| `components/Guide.tsx` | кирпичи гайда: шапка, инфографика, врезка, источники, CTA |
| `public/guides/<slug>/` | инфографики гайда |
| `tailwind.config.ts` | палитра: поменяешь акцент — поменяется весь сайт |

## Деплой

```bash
node scripts/site-deploy.mjs
```

Скрипт делает **две команды подряд** — `vercel deploy --prod` и `vercel alias set`.
Второй шаг обязателен: без него домен остаётся на предыдущей сборке, а страница
выглядит так, будто деплой не сработал.

Первый раз потребуется вход: `npx vercel login` (кнопка «Continue with GitHub»).

## Локальный просмотр

```bash
npm install
npm run dev      # http://localhost:3000
```
